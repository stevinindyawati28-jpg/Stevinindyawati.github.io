Struktur Model Data Relasional (SQL Schema)

Spesifikasi DDL SQL yang digunakan untuk integrasi backend Node.js / Express.js dengan MySQL / PostgreSQL.

users Pengguna/Guru
  • id INT (PK, AUTO)
  • nip_nik VARCHAR(30)
  • nama_lengkap VARCHAR(100)
  • username VARCHAR(50)
  • role ENUM('admin','guru')
classes Master Kelas
  • id INT (PK, AUTO)
  • nama_kelas VARCHAR(20)
  • tingkat INT (10,11,12)
  • tahun_ajaran VARCHAR(10)
  • wali_kelas_id INT (FK)
students Master Siswa
  • id INT (PK, AUTO)
  • nis VARCHAR(20) UNIQUE
  • nisn VARCHAR(20) UNIQUE
  • nama_lengkap VARCHAR(100)
  • jenis_kelamin ENUM('L','P')
  • class_id INT (FK)
attendances Presensi Harian
  • id INT (PK, AUTO)
  • student_id INT (FK)
  • class_id INT (FK)
  • subject_id INT (FK)
  • tanggal DATE
  • status ENUM(H,S,I,A,B,T)
grades Nilai Akademik
  • id INT (PK, AUTO)
  • student_id INT (FK)
  • subject_id INT (FK)
  • tugas_1, tugas_2, tugas_3 FLOAT
  • uh_1, uh_2 FLOAT
  • uts, uas FLOAT
grading_weights Bobot Nilai
  • id INT (PK, AUTO)
  • class_id INT (FK)
  • subject_id INT (FK)
  • bobot_tugas, uh, dll INT
